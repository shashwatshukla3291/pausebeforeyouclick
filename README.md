# Pause Before You Click

A simple website that checks messages for common scam warning signs and suggests safer next steps.

**Live site:** https://shashwatshukla3291.github.io/pausebeforeyouclick/

## What it does

- Checks for urgency, password or code requests, payment requests, and suspicious links
- Explains which warning signs it found
- Suggests safer ways to verify a message
- Keeps the check in your browser; it does not send or save the message

## Built with

HTML, CSS, and JavaScript.

## Important

This is an educational helper, not a guarantee that a message is safe. It can miss scams or flag legitimate messages.
When in doubt, contact the organization through its official app or a number you already trust.
